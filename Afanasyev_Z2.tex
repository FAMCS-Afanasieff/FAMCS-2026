\section{Постановка задачи}

На поле $n\times n$ выкладывают костяшки $1\times2$; виден цвет последней.

\section{Главная идея: снимаем костяшки с конца}

Снимаем с конца. Самая последняя костяшка лежит поверх всех.
Правило снятия: костяшку цвета $c$ можно снять с пары соседних
нефоновых клеток, если каждая из них либо свободна, либо показывает $c$.
Порядок снятия не важен (жадный процесс корректен).

\section{Режим 1: запас костяшек}

$\mathrm{need}_c = |S_c| - \nu_c$, где $\nu_c$~--- макс. число
непересекающихся пар соседних клеток цвета $c$. Разрешимо iff
(a) достижимо, (б) $a_c \ge \mathrm{need}_c$.

\section{Режим 2: заданная последовательность цветов}

Снимаем строго в обратном порядке: $c_m, c_{m-1}, \dots, c_1$.
Перебор всех допустимых позиций с отсечениями:
\begin{itemize}
  \item необъяснённых клеток цвета $c$ не больше $2\times$ оставшихся;
  \item нет замурованных клеток без нефоновых соседей;
  \item запоминание неудачных состояний (транспозиция).
\end{itemize}
Перебор полный, ответ <<невозможно>> достоверен.

\section{Обобщения 3--4: сколько бывает итоговых картин}

Прямой BFS: кладём костяшки всеми возможными способами,
складываем картины в множество. Для $2\times2$ с запасом $\{1:1,2:1\}$
получается $28$ картин; для последовательности сперва~1, потом~2~--- $16$.

\section{Проверка корректности}

\begin{itemize}
  \item Примеры из условия (точный запас, излишек, недостаток);
  \item Рисунок из \texttt{examples/pdf\_pattern.txt};
  \item \texttt{stress.py}: 500 случайных партий;
  \item Полная сверка на $2\times2$ и $3\times3$.
\end{itemize}
