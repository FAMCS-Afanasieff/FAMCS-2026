\section{Постановка задачи}

На поле $n\times n$ по линиям клеток выкладывают костяшки $1\times2$.
В клетке виден цвет последней накрывшей её костяшки. Режимы:
\begin{enumerate}
  \item дан запас костяшек ($a_1,\dots,a_k$); порядок любой;
  \item дана последовательность цветов $c_1,\dots,c_m$; порядок фиксирован.
\end{enumerate}
Обобщения 3--4: посчитать число различных итоговых картин.

\section{Главная идея: снимаем костяшки с конца}

Смотреть на игру удобно задом наперёд: снимаем костяшки, начиная
с последней. Самая последняя костяшка лежит поверх всех, поэтому обе её
клетки на картине показывают её цвет. Когда снимаем, клетки становятся
свободными. Клетки фона нельзя накрывать ни разу.

Правило снятия: костяшку цвета $c$ можно снять с пары соседних
нефоновых клеток, если каждая из них либо уже свободна, либо показывает
цвет $c$. После снятия обе клетки свободны.

\paragraph{Порядок снятия не важен.} Снятие костяшки лишь превращает
клетки в свободные, что может только помочь остальным снятиям.
Поэтому жадный процесс (снимаем что снимается) корректен.

\section{Режим 1: запас костяшек}

Пусть $S_c$~--- клетки цвета $c$. Максимальное число непересекающихся
пар соседних клеток из $S_c$ обозначим $\nu_c$. Минимально необходимое
число костяшек цвета $c$ равно
\[
  \mathrm{need}_c = |S_c| - \nu_c.
\]

\paragraph{Критерий.} Режим 1 разрешим тогда и только тогда, когда
(а) картина достижима (жадная проверка), (б) $a_c \ge \mathrm{need}_c$
для каждого цвета. Излишек $a_c - \mathrm{need}_c$ прячется на любую
пару соседних нефоновых клеток.

Программа строит порядок, снимая костяшки с конца (MRV-эвристика),
максимальное $\nu_c$ находит через поиск максимального паросочетания
на шахматной раскраске (Кун).
